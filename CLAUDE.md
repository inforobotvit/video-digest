# Video Digest – правила для Claude Code

Сервис: ссылка или файл с видео → очищенный транскрипт и структурированная выжимка.

## Где что
- `docs/` – источник правды. Перед любой работой читай `docs/contract-api.md` и `docs/result-schema.md`.
- `media-service/` – FastAPI, медиа-обработка. ТЗ: `docs/TZ-media-service.md`.
- `n8n/workflows/` – экспорт флоу n8n. `n8n/prompts/` – промпты LLM-этапов, версионируются здесь, не в нодах.
- `frontend/` – React + Vite + TS. Бриф: `docs/design-brief.md`.
- `infra/` – docker-compose, nginx, sql.

## Как работаем
- Работаешь только в папке, которую назвали в задаче. Другие не трогаешь.
- Перед кодом – вопросы. Потом шаг, показать, ждать «ок». Каждый шаг – коммит.
- Схемы данных не менять без правки `docs/` в том же коммите.
- Промпты пишешь на английском, требование к языку вывода – явно в промпте.
- Язык общения – русский. Комментарии в коде – английский.
