# Аналоги

Обзор на сентябрь 2026, для слайда «Аналоги» и раздела «Что дальше».

## Рынок

Инструменты «видео → выжимка» – массовый и однородный сегмент. Все построены одинаково: субтитры платформы, если есть, иначе распознавание речи, затем LLM превращает текст в структурированную выжимку. Архитектура – не отличие. Отличия – в том, где живёт результат, есть ли транскрипт, можно ли задавать вопросы по видео, какие платформы и форматы поддержаны, и как это стоит.

## Зарубежные

| Сервис | Формат | Что даёт | Чего нет |
|---|---|---|---|
| NoteGPT | веб, без регистрации | транскрипт, субтитры, короткая выжимка, главы, mind map, флэшкарты, чат | только YouTube |
| Eightify | расширение Chrome | ключевые моменты с таймкодами на странице YouTube, самый дешёвый | транскрипт, чат, библиотека |
| Recall | веб + расширение | до 10 часов, работает без субтитров, режимы «кратко / подробно / чат», библиотека | русские платформы |
| Marqly | расширение | карточка на странице просмотра: TL;DR, разделы, синхронный транскрипт, чат | загрузка файлов |
| Glasp | расширение | выжимка внутри экосистемы выделений и заметок | самостоятельный продукт |
| Youlearn | веб, есть русский | конспект, флэшкарты для самопроверки, транскрипт, чат | российские платформы |
| Notta, HappyScribe, Otter | веб | точная транскрипция, спикеры, языки; выжимка сверху | структура результата |

Вывод обзоров рынка: качество выжимки у всех сопоставимо, потому что все используют модели одного класса; конкуренция идёт за место, где живёт результат, и за рабочий процесс вокруг него.

## Где Video Digest отличается

1. **Один документ с регулятором глубины.** У всех – «выжимка» и «транскрипт» отдельно, вкладками или колонками. У нас – один текст, который раскрывается от TL;DR до транскрипта, с осью-таймлайном и пометками на полях.
2. **Пресеты и критика.** У аналогов – «кратко / подробно». У нас – пресет под тип контента (лекция, совещание, доклад, интервью) и блок критики аргументации: где обосновано, где слабо, чего не хватает. Критики нет ни у кого.
3. **Российские платформы и файлы.** VK Видео, Rutube, загрузка видео и аудио (диктофон). Зарубежные знают YouTube, российские – YouTube и файлы.
4. **Контроль качества, а не доверие модели.** Тезис без таймкода не принимается, цитата проверяется по транскрипту программно, вердикт проверки фактов без источника невозможен, стилевые правила проверяются регулярками с повтором.
5. **Прозрачная стоимость.** Каждый этап пишет цену в meta – основа для честных кредитов вместо «безлимита».
6. **Локальный контур.** STT и LLM переключаются на self-hosted одной переменной окружения, весь сервис – один compose. Массовые сервисы работают только через облако; для корпоративного сегмента (совещания, обучение, звонки с клиентами) это ключевое отличие.

## Что есть у аналогов и нет у нас (в «Что дальше»)

- Чат по видео (Recall, Marqly, NoteGPT, Youlearn) – транскрипт уже в контексте, добавить дёшево.
- Библиотека сохранённых результатов и поиск по ним (Recall, Marqly) – после аккаунтов.
- Расширение для браузера с карточкой на странице просмотра (Eightify, Marqly).
- Флэшкарты (NoteGPT, Youlearn) – у нас есть `self_check`, это один шаг.
- Диаризация (Notta, Speech2Text) – в плане, вторая итерация.
