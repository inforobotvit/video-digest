Пресет — это набор галочек по умолчанию, а не запрет: в «Просто выжимке» всё снято, но добавить блок можно. Оценка времени пересчитывается по галочкам. Пунктирный «Turnstile» — где живёт виджет: рядом с кнопкой, внутри раскрытой карточки. На телефоне опции в одну колонку, кнопка во всю ширину.

Список опций и их состав по пресетам здесь условные — набор берётся из контракта.
