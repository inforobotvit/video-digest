# Video Digest – вопросы и ответы для отчёта

Обновлено 9 сентября 2026. Сервис в проде: https://digest.inforobot.space

## О продукте

**Что это?**
Сервис, который превращает видео или аудио в документ: очищенный транскрипт и выжимку с тезисами, привязанными к секундам записи. Ссылка на YouTube, VK Видео, Rutube, прямая ссылка или файл, включая диктофонную запись.

**Какую проблему решает?**
Длинное видео нельзя прочитать – только смотреть целиком. Документ читается за минуту, пять или целиком, и в любом месте можно нажать на таймкод и услышать оригинал.

**Для кого?**
Наружу – для тех, кто смотрит лекции, доклады, подкасты и записи встреч и хочет читать вместо смотреть. Внутрь – для компаний: конспекты записей, которые нельзя выносить за периметр.

**Чем отличается от аналогов?**
Один документ с регулятором глубины вместо вкладок «выжимка / транскрипт». Пресеты под тип контента и критика аргументации – её нет ни у кого. Российские платформы и файлы. Результат проверяется программно: тезис без таймкода отбраковывается, цитата сверяется с транскриптом, таймкоды цитат берутся из транскрипта, а не от модели. Локальный контур одной переменной.

**Чем отличается от «кинуть ссылку в Gemini»?**
Ничем, если нужен разовый ответ «о чём видео». Разница – когда нужен документ: он живёт по ссылке 30 дней, экспортируется в шесть форматов, играет видео рядом с текстом, имеет одинаковую структуру на любом ролике, умеет VK, Rutube и диктофон. Gemini – спросить, Video Digest – получить конспект, который останется.

**Можно ли развернуть внутри компании?**
Да, заложено с первого дня. STT и LLM переключаются на self-hosted серверы с OpenAI-совместимым API (Whisper в контейнере, Ollama / vLLM / GigaChat в контуре) одной переменной окружения. Поиск для проверки фактов отключается. Весь сервис – один docker compose, деплой по гайду.

**Что с персональными данными?**
Не собираем. Аккаунтов нет, почты нет – убрали, потому что галочка согласия не закрывает 152-ФЗ, а регистрироваться оператором ПДн ради письма неоправданно. Результат живёт по ссылке 30 дней, список своих задач хранится в браузере, уведомление о готовности – через браузер. Загруженный файл удаляется сразу после обработки, остаётся аудиодорожка для плеера.

**Сколько стоит одно видео?**
Реальные прогоны на проде: 15-минутная речь с субтитрами – 5 центов; 9-минутный ролик без субтитров – 10 центов; часовая лекция без субтитров – 42 цента, из них 35 – распознавание речи. Обработка часа – около 5 минут. Стоимость каждого этапа пишется в базу с первого дня.

**Монетизация?**
Не в MVP. План – кредиты, опции влияют на цену; для компаний – тариф с локальным контуром.

## О технологии

**Как устроено?**
Пять слоёв: фронт (React), оркестрация (n8n), медиа-сервис (FastAPI: yt-dlp, ffmpeg, субтитры, нарезка по тишине), STT (Whisper через API или локально), LLM (чистка → выжимка map-reduce → дополнительные блоки). Postgres с одной таблицей задач. Всё в одном compose, на VPS за системным nginx с HTTPS.

**Почему n8n, а не свой бэкенд?**
Оркестрация – это связывание готовых API с состоянием и повторами, n8n делает это наглядно. Всё, что требует кода – работа с медиа – вынесено в отдельный сервис на Python со 105 тестами. Флоу n8n генерируются скриптом и лежат в репозитории как json, восстанавливаются на чистом инстансе одной командой.

**Как контролируете качество выжимки?**
Схема результата зафиксирована в JSON Schema. Каждый ответ модели валидируется. Жёсткие правила роняют ответ: таймкоды только из абзацев транскрипта, цитаты дословные, структура без дыр. Стилевые правила – мета-зачины, родовые заголовки, пересказ спикера, тезис-перечисление – после неудачного повтора принимаются с предупреждением в meta. Повтор не генерирует заново, а исправляет отклонённый ответ: модель получает свой ответ и текст ошибки и меняет только названное. Промпты калибровались на реальных видео и переписывались по конкретным дефектам.

**Почему две модели?**
Дешёвая (gpt-4o-mini) на map-этапах, где много вызовов и простая задача. Сильная (gpt-4.1) на reduce и критике, где один вызов на видео и нужно держать десяток правил. Стоимость LLM всё равно в разы меньше STT.

**Что с ошибками распознавания?**
Whisper на русском хорош, но не идеален. Этап чистки исправляет очевидные ошибки по контексту, не сокращая и не пересказывая. Известные тексты (песни, знаменитые речи) OpenAI отказывается воспроизводить дословно – для этого есть запасной путь чистки по правилам.

**Проверка фактов – это правда?**
Экспериментальная опция, помечена так в интерфейсе, сейчас отключена. Дизайн: модель выделяет 5–10 проверяемых утверждений, ищет источники, вердикт без источника невозможен. Это помощь в проверке, не истина.

**Как устроен деплой?**
GitHub Actions: CI на каждый push (тесты медиа-сервиса, фронта, валидация фикстур по схеме, e2e Playwright), деплой по кнопке в Actions с проверкой, что CI по этому коммиту зелёный. На сервере фиксированный скрипт: чистый снимок коммита, сборка образов с тегом SHA, health check, откат на предыдущий образ при неудаче. Отдельный пользователь без sudo, ключ только для чтения репозитория. Деплой – около минуты.

**Что не сделано?**
Диаризация (кто говорит), проверка фактов, чат по видео, библиотека результатов, аккаунты. Повтор упавшей задачи заново транскрибирует – надо переиспользовать транскрипт. Всё записано в журнал решений с обоснованием.

## О процессе

**Как это делалось?**
Шесть дней по 4–5 часов, один человек в роли продакта и арт-директора, три инструмента: Claude как архитектор и редактор, Claude Code как разработчик, Claude Design как дизайнер. Ни строчки кода руками.

**В чём была моя роль?**
Решения: отказаться от несерьёзного проекта, сделать сервис наружу, идея документа с глубиной (из замечания «скучно» на три аккуратных макета), диагноз качества выжимки («дело в заголовках»), плеер для аудио, убрать почту из-за 152-ФЗ, локальный контур как позиционирование. Приёмка каждого шага: показать, дождаться «ок», коммит. Чтение реальных выжимок как читатель – именно так нашёлся баг с таймкодами на часовой лекции.

**Как контролировали ИИ?**
Документы как источник правды: контракт API, схема результата, ТЗ, бриф, гайд по деплою – читаются инструментами как договор. CLAUDE.md в каждой папке ограничивает область работы. Шаги маленькие, каждый с приёмкой и отдельным коммитом. Журнал решений. Промпты в репозитории под валидаторами. Одна сессия – один шаг, чтобы контекст не деградировал. CI ловит то, что агент не проверил: два раза поймал устаревшие фикстуры и один раз непрогнанный prettier.

**Что пошло не так?**
Первая выжимка была слабой – модель игнорировала половину правил; починили заменой модели на reduce и регулярками. Дизайн первого прохода был скучным – потому что бриф просил «инструмент»; починили одной идеей про глубину. На часовой лекции все таймкоды оказались нулями – модель на длинном куске возвращала один абзац; починили короткими кусками и валидацией времени. Русские стилевые правила молча не работали из-за `\b` в JS после кириллицы – когда заработали, начали ронять часовые прогоны; ответ – мягкие правила и повтор-исправление. Rutube не играл в свёрнутом плеере – iframe был обрезан. Ассистент дважды вышел за границы папки – напомнили правило. Один раз задеплоил не тот коммит – запустил деплой раньше пуша.

**Сколько стоило?**
Подписка на инструменты плюс около трёх долларов на API OpenAI за все прогоны, включая часовые. Время – шесть дней по 4–5 часов.

**Что дальше?**
Повтор без повторной транскрибации, проверка фактов, диаризация, чат по видео, аккаунты и кредиты, корпоративная версия в контуре. И статья о том, что остаётся человеку, когда код и дизайн делают инструменты.
