# frontend – веб-клиент Video Digest

React 19 + Vite + TypeScript. Статика, отдаётся nginx из `infra/`, ходит только в `/api/`.

## Источник правды
- `../docs/design-brief.md` – что за экраны и как они себя ведут. Макеты из Claude Design – как они выглядят. При расхождении макета и брифа – спросить.
- `../docs/contract-api.md` – все ручки, статусы, коды ошибок, `estimate.per_option`. Ничего сверх контракта фронт не ждёт.
- `../schemas/result.schema.json` – типы результата, из него генерируются TS-типы. `../docs/result-schema.md` – смысл полей, правила рендеринга (п. 4: тезисы, цитаты, пометки привязываются к части structure по start).
- `../n8n/fixtures/result-sample.json` и `../n8n/fixtures/real/*.json` – тестовые данные. Страница результата собирается на них до подключения API.

Заход E4 (2026-09-30): одна страница от ссылки до запуска (`pages/HomePage.tsx`: поле → карточка без кнопок → язык результата → аккордеон пресетов `components/home/PresetAccordion.tsx` с запуском и Turnstile внутри раскрытой строки); пресет – умолчания галочек, `options` в POST /api/jobs – итоговый список (`lib/settings.ts`); звёзды в опросе (`components/feedback/FeedbackModal.tsx`, radiogroup 1–5); цифры лимитов на странице – из `GET /api/limits` (`api.limits()`, один вызов на загрузку главной, без ответа форма работает без чисел), констант с лимитами во фронте нет; закрытие опроса без ответа глушит таймер на сутки (`lib/feedback.ts`). Скриншоты шагов – `docs/design/sketches/`. Дальше – второй проход дизайна, когда придёт. Почты нет (решение 2026-09-09): `email` в POST /api/jobs не отправляем, типы контракта не трогали; подвал `components/Footer.tsx` со ссылкой на политику везде, кроме результата и самой политики. Контакты (2026-09-11): `lib/contacts.ts`, в шапке справа от темы иконки Mail и Send, в подвале «Виталий Туров · @mewithrobot». Визитка `/about/` – статика `public/about/` (тёмная `index.html`, `light.html`, шрифты и картинки рядом, внешних запросов нет), роутер её не знает; в dev и preview путь `/about` и `/about/` на файл маппит плагин в `vite.config.ts`, e2e – `e2e/about.spec.ts`. «Мои задачи» – `lib/jobsStore.ts`, localStorage `jobs`, последние 10, пишутся при создании (главная, retry), обновляются при открытии `/jobs/{id}`, на сервер не уходят. Уведомление браузера – `lib/notify.ts`: мягкая строка на ожидании только для задач из `jobsStore`, ответ запоминается в localStorage `notify`, срабатывает при `done`/`failed` в фоновой вкладке; без service worker закрытая вкладка не уведомляется. Плеер: `src/player/` (бэкенды и хук), `src/components/player/`; embed для VK и Rutube собирает `lib/playback.ts`. Проверка воспроизведения – `node scripts/player-check.mjs [url] [youtube|rutube]` при поднятом `npm run dev` (headless Chrome через CDP; вкладка автоматизации медиа не грузит). Мобильная раскладка до 720px включительно: порог в CSS и в `lib/useMediaQuery.ts` один; оглавление на мобильном – шторка `result/TocSheet.tsx`, ось общая с сайдбаром (`result/Toc.tsx`). Тема: `lib/theme.ts`, `data-theme` на html, выбор в localStorage, без выбора – системная; цвета только через токены `styles/tokens.css`, палитра глав – переменные `--ch-N`. Тесты: `npm test`, `ResultPage.test.tsx` рендерит результат на всех фикстурах в jsdom и падает на любом console.error. Ось (2026-09-09): два положения – чтение (`lib/useReading.ts`: глава, чей верх выше трети экрана, по краям первая и последняя; клик по таймкоду или пункту оглавления закрепляет главу до собственного скролла читателя; `aria-current` на пункте, чип липкой панели – по чтению) и плеер (засечка, только после первого play/seek – `PlayerState.started`; строка главы в тексте и полоска аудиоплеера по-прежнему от плеера). Тест – `e2e/scrollspy.spec.ts`.
- Шаги: (1) каркас, типы из схемы, страница результата на фикстуре; (2) главная, карточка, настройки; (3) ожидание с опросом статуса; (4) плеер, экспорт, поделиться, ошибки; (5) мобильный, тема – когда придут макеты. Каждый шаг – показать, ждать «ок», коммит.
- API-клиент – один модуль, базовый URL из env (`VITE_API_BASE`, по умолчанию `/api`). В dev – прокси Vite на `http://localhost` (nginx из compose).
- Опрос статуса раз в 3 с, остановка на `done` / `failed`, вкладка в фоне – раз в 10 с.
- Состояние – в URL: `/` главная, `/jobs/{id}` ожидание и результат. Без роутер-библиотеки, если хватает `history`.
- Никаких UI-библиотек и CSS-фреймворков: стили из макетов, CSS-переменные для темы, один файл токенов. Иконки – Lucide.
- Плеер: YouTube / VK / Rutube – iframe их плеера с перемоткой по API; `direct` – `<video>`/`<audio>`; `audio` – `<audio>` на `/api/jobs/{id}/media`. Клик по любому таймкоду – перемотка, не переход.
- Тексты интерфейса – из макетов, вынести в один модуль строк. Язык интерфейса только русский.
- Не показывать: стоимость, `language_confidence`, коды ошибок крупнее серой строки под сообщением.
- Ничего не выдумывать сверх данных: если поля нет в схеме – его нет на экране.
- Общение – по-русски, код и комментарии – по-английски.
