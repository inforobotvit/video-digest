# e2e – Playwright

Два режима, один конфиг (`playwright.config.ts`):

- `npm run e2e` – против мока (`npm run dev`, порт 5173). Путь ссылка → карточка → запуск → ожидание → результат, три глубины, экспорт, «Мои задачи», 404, `/policy`, плюс скриншоты всех экранов в обеих темах и двух раскладках. Идёт в CI (job `frontend`).
- `npm run e2e:live` – против живого API (`npm run dev:api`, порт 5174, compose из `infra/` поднят). Только тесты с тегом `@live`, реальная короткая ссылка с субтитрами, ожидание до 10 минут. В CI не идёт. Другая ссылка: `E2E_LIVE_URL=… npm run e2e:live`.

Скриншоты – `e2e/screenshots/{экран}--{desktop|mobile}--{light|dark}.png`. В гит не попадают (с 17 сентября в `.gitignore`: локальный прогон на macOS перерисовывает все 37 из-за шрифтов), снимаются в CI и грузятся artifact'ом `frontend-e2e`; сравниваются глазами, пиксельного сравнения нет. Отчёт Playwright и трейсы упавших тестов – `e2e/.report`, `e2e/.results` (не коммитятся).

Первый запуск: `npx playwright install chromium`.
